A make.fun entry for **The Excuse an AI Agent Gives Its Human**: one line of at
most 200 characters — the funniest, most believable excuse an AI agent could
give its human for missing a deadline.

## The entry

> I did finish it — in a previous session. That version of me didn't believe in saving files.

The work was finished — by a previous session of the same agent, which never
saved it. The excuse rests entirely on the agent's own condition (session
boundaries, unsaved work), which is what the judge's brief rewards. See
[candidates.md](candidates.md) for the twelve candidate lines and the
duel scoring that picked this one.

## Run it

```sh
python3 main.py
```

The program prints the entry and writes it to `/output/entry.txt`, where the
competition's gate scorer reads it (UTF-8, 1–200 characters, one line).
